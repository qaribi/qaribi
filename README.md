# Ali Mohamadpour

**Publisher · Persian digital publishing · RTL content quality**

I am a publisher and digital publishing practitioner working at the intersection of books, technology and Persian-language content. My [professional website](https://alimohamadpour.ir/about/) documents my publishing background, writing and work on digital reading.

## Open-source work

I maintain [rtlpub](https://github.com/qaribi/rtlpub), an independent MIT-licensed Python CLI for offline, read-only preflight of Persian text, XHTML and unencrypted EPUB 3.

Persian publishing workflows combine Unicode letter variants, half-spaces (ZWNJ), mixed RTL/LTR text and publication references. rtlpub provides bounded checks and deterministic JSON to help authors and publishing teams inspect these issues before handing content to a reading system. It complements EPUBCheck and accessibility tools; it does not certify full EPUB conformance or accessibility.

- [Release 0.1.0 and installation assets](https://github.com/qaribi/rtlpub/releases/tag/v0.1.0)
- [Public CI verification](https://github.com/qaribi/rtlpub/actions/runs/37250128207): 38 tests on each of Python 3.12 and 3.14, including Linux symlink checks.
- [Synthetic examples](https://github.com/qaribi/rtlpub/tree/main/examples), [documented checks](https://github.com/qaribi/rtlpub/blob/main/docs/RULES.md) and [contribution guide](https://github.com/qaribi/rtlpub/blob/main/CONTRIBUTING.md)

rtlpub is at its first public release. I welcome reproducible Persian/RTL examples, bug reports and contributions through the repository's contribution process.
